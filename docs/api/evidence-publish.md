in Appendix J of the Typed Standards specification
([civic-ai-tools#160](https://github.com/npstorey/civic-ai-tools/issues/160)).

only for its epistemic sense.

filename: `POST /api/records` and its permanent alias `POST /api/evidence` both
serve, and every request and response shape documented at the new location
